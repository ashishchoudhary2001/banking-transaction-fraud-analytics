# Capstone 1 — Banking Transaction & Fraud Analytics

## Business problem
A retail bank wants to understand transaction performance, customer activity, channel behavior and potential fraud patterns.

## Questions
- Which transaction types drive value and volume?
- How does activity change month to month?
- Which cities and customer segments contribute most?
- Which channels show elevated fraud rates?
- Which customers and transactions require attention?

## Tools
MySQL/SQL, Excel, Power BI.

## Dashboard
1. KPI cards: Transactions, Transaction Value, Average Transaction, Fraud Rate
2. Monthly transaction trend
3. Transaction value by type
4. Transaction value by city
5. Fraud rate by channel
6. Customer segment performance
7. High-risk transaction table

## Deliverables
- dataset.csv
- analysis.sql
- analysis_workbook.xlsx
- README.md

Dataset is synthetic and contains no real customer information.
